KNN Classification Model using Iris Dataset

This project implements a K-Nearest Neighbors (KNN) Classification Model using the famous Iris flower dataset from Scikit-learn.
streamlit link:https://mnveakzrvjkeclvytzn6gw.streamlit.app/
📌 Project Overview
The model classifies Iris flowers into three species:

Setosa
Versicolor
Virginica

using machine learning with the KNN Algorithm.

🛠 Technologies Used
Python
Scikit-learn
NumPy
Pandas
Matplotlib

📂 Dataset
The project uses the built-in Iris Dataset available in Scikit-learn.
Features:
Sepal Length
Sepal Width
Petal Length
Petal Width

Target:
Flower Species
⚙️ Steps Performed
Import libraries
Load Iris dataset
Split dataset into training and testing sets
Create KNN classifier model
Train the model
Predict test data
Evaluate model accuracy

📌 KNN Algorithm
KNN (K-Nearest Neighbors) is a supervised machine learning algorithm used for classification and regression.

Working:
Finds the nearest K data points
Uses majority voting for classification
Distance Metrics:
Euclidean Distance
Manhattan Distance
Minkowski Distance
Hamming Distance

📊 Model Evaluation
The project evaluates the model using:
Accuracy Score
Confusion Matrix
Classification Report

The model prints:
Accuracy
